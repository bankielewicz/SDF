# ADR-011: Reports are written once per phase and never edited

## Context

The first cycle left this undecided and two files disagreed about it.

## Decision

Reports are written once per phase and never edited, recorded here so the context files can cite one source.

## Consequences

| Consequence | Direction | Affected |
|---|---|---|
| A file that predates the decision follows it when next touched | cost | none |
