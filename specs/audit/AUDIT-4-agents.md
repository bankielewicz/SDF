### AGT-019, AGT-020, AGT-021 · reconcile the severity rule with the ratio

`specs/07-verify.md` `## Send-back` states one rule: a `warn` finding lands in the report and sets no gate; a `block` finding lowers `passed` below `total` and fails the `verifier_pass` check. Three agents break it, two in one direction and one in the other. The fix is per agent, and the rule is the arbiter.

**`standards-reviewer`.** Today every finding is `warn`, so `passed` equals `total` on every input and `verify-light` cannot fail on it. Either the agent gains a `block` case or the registration is honest about being a reporter. Recommended: gain the case. `## Output` prose becomes "a standards finding is `warn`, except a departure from a rule a `CON-nnn` in `constraints` binds, which is `block`" — the agent already receives `constraints` as "the `## Constraint index` rows whose `Enforced by` cell names a standards rule" and cites them at workflow step 6, so the data is in hand and only the severity mapping is missing. `passed` then measures something.

**`dead-code-detector`.** Today a `warn` finding lowers `passed`, which fails a gate the phase spec says `warn` does not reach. Recommended: keep the severity and break the coupling. `passed` becomes "the number of symbols examined", equal to `total`, and the dead-symbol count moves to a new top-level `dead` integer that `report ingest` copies through. The `verify-light` check stops firing on a `warn`, and a project that wants dead code to gate adds a `report_metric` check on `verifiers.dead_code.dead` to its own `gates.toml`. The alternative — raising the finding to `block` — gates on a Grep count the agent rates at `confidence: 0.6`, which is the worse trade.

**`code-quality-auditor`.** Same shape, same fix: `passed` becomes `total`, and `over_ceiling` carries the count of files above either ceiling as a top-level extra key. A project wanting complexity to gate adds a `report_metric` check, which is where a threshold the project chose belongs.

All three changes land in `specs/07-verify.md` §Subagents, the three agent files, and catalog entries 26, 30, and 33. `skills/validating-quality/agents.md`'s closing paragraph on the severity mapping gains the two exceptions.
