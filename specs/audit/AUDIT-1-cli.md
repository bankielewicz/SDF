## Gate engine shortcuts

What holds. `DFA-E302` for an unknown key is enforced uniformly: `gates.rs::parse_check:462` rejects any key outside `kind_keys(kind)` plus `COMMON_KEYS`, `gates.rs::condition:544` rejects any condition key outside `{path, field, equals, in, state_field, is_empty, doc_exists}`, and `gates.rs::parse_check:479` rejects an unknown `kind` as `DFA-E301`; `kind_keys` matches the spec table key for key across all 30 kinds. `gate.rs::evaluate:393` converts `DFA-E200`, `DFA-E401`, and `DFA-E345` into a check failure, so kinds that propagate those fail closed. `substitute` and `project::resolve_doc_path` are applied on every `path`, `paths`, and `docs` key. The compiled minimums are enforced at load: `gates.rs::validate_minimums:610` from `gates.rs:309` checks required kinds at `severity = "block"` for all eight phases and the verify `min_ratio` floor, with `DFA-E303` for a required kind carried at `severity = "warn"`; `config.rs::validate_minimums:656` from `config::load:719` checks the layer and overall floors, skips them while `degraded` is set, and `coverage.rs::layer_order:399-411` backfills a deleted `[[layer]]` at a default above its floor. Tests exist at `gates.rs:676,769,794,813` and `config.rs:854,866,877,892`. The degraded skip set at `gate.rs:396` matches spec 306 exactly, `--no-run` is a spec'd flag (spec 895), and no kind returns `errors_table::NOT_IMPLEMENTED`, so the stub machinery at `gate.rs:202-207,271-277,2701-2731` is wired and unreachable.

What does not hold, across every kind: no required-key validation at load. Every key the spec table marks required (`paths`, `path`, `field`, `values`, `section`, `column`, `pattern`, `state_field`, `verifiers`, `cover`, `universe`, `docs`, `metric`, `started_field`, `limit_field`, `doc`, `from`, `to`, `into`) is read through `str_key` or `arr_key` with a silent default. `validate_minimums:620` checks that a required *kind* is present at block severity and never inspects that kind's keys, so a check whose required key is omitted satisfies the compiled minimum and then passes vacuously. That is the shared root of CLI-104, CLI-132, CLI-141, CLI-143, CLI-144, CLI-145, CLI-146, CLI-147, CLI-149, CLI-152, and CLI-153.
